# Media_aluno

Sistema em Python para calcular a média de um aluno.

## O que o programa faz
- Pede o nome do aluno
- Pede 2 notas (de 0 a 10)
- Calcula a média
- Mostra se o aluno foi Aprovado ou Reprovado
- Aprovado = média maior ou igual a 6.0

## Como usar
1. Abra o arquivo main.py
2. Rode o programa
3. Digite o nome e as notas

## Tecnologias
- Python
- Funções
- Lista e dicionário
